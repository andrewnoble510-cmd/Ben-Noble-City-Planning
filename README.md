# Benjamin Noble — City Planning

## Live website

[**Visit the Ben Noble City Planning website →**](https://andrewnoble510-cmd.github.io/Ben-Noble-City-Planning/)

The site is published with GitHub Pages and automatically updates when changes are pushed to `main`.

A design-only, responsive single-page website concept for Benjamin Noble.

The site intentionally uses neutral labels and visual placeholders so real biography, services, projects, and contact details can be added later.

Service pages:

- `planning.html`
- `policy.html`
- `engagement.html`
- `design.html`

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server:

```powershell
python -m http.server 4173
```
